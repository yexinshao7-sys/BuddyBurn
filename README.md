# BuddyBurn V1

A lightweight iPad-friendly PWA prototype for two-person workout accountability.

## Included
- White × Lavender visual system
- English / 简体中文 / 繁體中文
- Home dashboard
- Weekly workout plan
- Workout completion/check-in
- Buddy status
- Encouragement toast
- Lightweight buddy chat
- Video recommendation placeholders
- Theme area prepared for future color themes
- LocalStorage demo persistence
- PWA manifest + service worker

## Run locally
Serve this directory from a local HTTP server, e.g.:
`python3 -m http.server 8080`
Then open `http://localhost:8080`.

This is a frontend prototype. Real accounts, cloud sync, push notifications, video APIs and App Store packaging should be added in the next phase.
